# Launch Check — 1.1.0

Research search opportunities and prepare public websites for launch with an evidence-first Agent Skill.

This release includes research, audit, implementation, and launch modes; a capability preflight and setup gate; free-first Google Trends and Keyword Planner research; GDPR/cookie checks; logo/home and social-preview verification; intent clustering and page briefs; technical SEO and AI-search guidance; scoped security and analytics checks; and a reusable verification report.

It improves the original checklist with explicit unknown-data handling, upfront tool/connectivity verification, current FAQ and AI-search guidance, actionable fix ownership, founder-friendly output, conditional approvals, rollback planning, and verification on the deployed site.

The skill is instruction-only. It works with the tools supplied by its host and has no required paid SEO provider or bundled service connection. Missing tools or data are reported explicitly.

Package validation and manual instruction-level scenario review are documented in `docs/VALIDATION.md`. Live-site execution, independent agent behavior, cross-host installation, and ranking outcomes have not been established by this release review.

Licensing and public distribution must be finalized by the publisher before presenting this as an open-source release.
